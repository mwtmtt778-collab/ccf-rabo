# 03 系统架构

## 入口

- [VERIFIED] `main.py` 是当前入口文件。
- [VERIFIED] `main.py` 定义 `DEFAULT_AGENT = "arm_hand_demo"`。
- [VERIFIED] `main.py` 当前定义 `RUN_ROBOT_STATE_TEST_ON_DEFAULT_START = True`。
- [VERIFIED] 无参数启动时，当前代码会先运行 `tools.test_robot_state.main()` 并返回。
- [VERIFIED] 带参数启动时，`main.py` 通过 `importlib.import_module(f"agents.{name}")` 加载 agent 子包，并要求子包暴露 `run()`。

## agents/

- [DOCUMENTED] `agents/` 是具体 agent 容器目录。
- [VERIFIED] 当前包含 `example_agent/`、`arm_hand_demo/`、`three_nut_expert/`。
- [VERIFIED] `agents/example_agent/` 是模板 agent，默认不接 LLM、不接输入源，`run()` 实例化后返回。
- [VERIFIED] `agents/arm_hand_demo/__init__.py` 包含 legacy 双臂抓取 / handoff 动作逻辑，会使用 `rabo_robocap` 和 `SetEntityPose`。
- [VERIFIED] `agents/three_nut_expert/` 包含参数化三螺母 Expert，默认包入口为 dry-run 合约输出。

## core/

- [VERIFIED] `core/base_agent.py` 提供 `BaseAgent`，负责 LLM 工具调用循环、消息历史、工具参数 JSON 容错。
- [VERIFIED] `core/base_agent.py` 不导入具体机器人 SDK 或具体 agent。

## drivers/

- [DOCUMENTED] `drivers/` 预留给可复用硬件 / 感知驱动。
- [VERIFIED] 当前 `drivers/__init__.py` 中 `__all__` 为空，尚无实际驱动实现。

## expert/

- [VERIFIED] `expert/` 当前是未跟踪源码目录。
- [VERIFIED] `expert/transforms.py` 提供 SE(3) 位姿变换工具，被工作空间 V2 坐标解析使用。
- [PENDING] `expert/` 是否应正式纳入 Git 跟踪需要用户确认后执行。

## tools/

- [VERIFIED] `tools/` 包含只读探针、相机测试、工作空间测试、三螺母运行器和 Git 辅助脚本。
- [VERIFIED] `tools/run_three_nut_expert.py` 默认 dry-run，真实机器人 / 仿真动作必须显式 `--execute`。
- [VERIFIED] `tools/test_dual_arm_reachability.py` 当前有未提交修改，加入坐标门禁逻辑。
- [VERIFIED] `tools/resolve_workspace_coordinates.py` 当前未跟踪，是工作空间 V2 坐标解析脚本。
