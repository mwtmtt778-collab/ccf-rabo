# 常见问题与解决办法

## 本机找不到 Rabo camera/state/control ROS topic

- 现象：[DOCUMENTED] 本机 runtime probe 只看到探针节点、`/parameter_events`、`/rosout`，未发现 Rabo camera/state/control。
- 原因：[DOCUMENTED] 本机不是 Rabo 云端 runtime，不能直接发现云端 DDS/SDK runtime。
- 检查：[DOCUMENTED] 运行 `tools/inspect_rabo_runtime.py` 或 ROS2 discovery 命令。
- 解决：[DOCUMENTED] 通过 GitHub 同步到 Rabo 云端，在真实 Rabo runtime 中执行只读探针。
- 验证状态：[DOCUMENTED] 已有本机探针报告；云端当前状态仍需现场确认。

## RGB 相机 topic 名称匹配失败

- 现象：[DOCUMENTED] 旧文档中记录过 known RGB topic 按 suffix 匹配时显示 MISSING，但带 `/gs_<id>/` namespace 的 topic 可以被采样。
- 原因：[DOCUMENTED] topic 可能带动态 runtime namespace，匹配逻辑必须接受带或不带 leading slash / namespace 的形式。
- 检查：[DOCUMENTED] 先运行 `ros2 topic list -t --no-daemon`，再搜索 `_tp_cam_`、`camera`、`image`。
- 解决：[DOCUMENTED] 使用 `tools/test_camera_stream.py` 的扫描逻辑，不只依赖裸 suffix。
- 验证状态：[DOCUMENTED] `docs/RABO_CAMERA_TEST_REPORT.md` 记录 left/right wrist RGB 曾采样到帧，fixed RGB 仍为 CHECK。

## 运行脚本污染 docs

- 现象：[DOCUMENTED] 历史上运行脚本可能生成或覆盖 tracked `docs/*.md`。
- 原因：[DOCUMENTED] 旧默认输出路径曾指向 `docs/`。
- 检查：[DOCUMENTED] 运行前后比较 `git status --short`。
- 解决：[DOCUMENTED] 当前规则是运行产物写入 `outputs/`，日志写入 `logs/`。
- 验证状态：[DOCUMENTED] `docs/GIT_WORKFLOW_REPORT.md` 记录 dry-run 后 Git dirty 状态不再新增变化。
