# 00 项目总览

## 项目目的

- [DOCUMENTED] 本项目是 Rabo 平台控制器工程，目标是在 Rabo 仿真 / 比赛环境中开发机器人 agent。
- [DOCUMENTED] 当前核心任务围绕双臂、双手、三螺母任务：先确认 runtime 接口、相机、工作空间和策略，再推进抓取、Recorder、ACT。
- [DOCUMENTED] README 描述了一个通用多 agent 模板，支持多个 agent 共用 `core/` 和 `drivers/`。

## 平台

- [DOCUMENTED] Rabo 平台会按 `requirements.txt` 安装依赖并运行 `python3 -u main.py`。
- [DOCUMENTED] Rabo LLM Key 通过环境变量 `RABO_LLM_KEY` 注入，不写入代码。
- [VERIFIED] 本地仓库路径为 `/home/liyi/agent_system`。
- [PENDING] Rabo 云端真实路径、remote 命名和 runtime 注入方式仍需现场确认。

## 总体路线

- [DOCUMENTED] 当前路线是：runtime 只读探测 -> 相机 / 状态接口确认 -> 工作空间 V2 -> 稳定性测试 -> 单螺母验证 -> 三螺母 Expert -> Recorder / Replay -> ACT。
- [DOCUMENTED] 工作空间 V2 未通过前，不进入 hover motion、抓取、handoff、Recorder 或 ACT。
